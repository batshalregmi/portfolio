# Batshal Regmi - Professional Website

A modern, responsive portfolio website showcasing the professional experience, projects, and skills of Batshal Regmi, a Computer Science student at Georgia Institute of Technology.

## Features

- **Responsive Design**: Fully responsive layout that works on desktop, tablet, and mobile devices
- **Modern UI/UX**: Clean, professional design with smooth animations and hover effects
- **Single Page Application**: Smooth scrolling navigation between sections
- **External Resume Link**: Links to a third-party site (Google Docs) for the full resume
- **Interactive Elements**: Animated typing effect, parallax scrolling, and interactive project cards
- **Social Media Integration**: Direct links to LinkedIn, GitHub, and email

## Sections

1. **Hero/Home**: Introduction with call-to-action buttons and social links
2. **About**: Personal introduction, technical skills, and educational background
3. **Experience**: Timeline view of professional experience and research roles
4. **Projects**: Grid layout showcasing featured projects with technology stacks
5. **Contact**: Contact information and resume download link

## Technologies Used

- **HTML5**: Semantic markup and structure
- **CSS3**: Modern styling with Grid, Flexbox, animations, and responsive design
- **JavaScript**: Interactive functionality, animations, and dynamic effects
- **Font Awesome**: Icons for social media and UI elements
- **Google Fonts**: Inter font family for typography

## Resume Integration

The website includes multiple links to an external resume hosted on Google Docs:
- Navigation bar "Resume" button
- Hero section "View Resume" button  
- Contact section "View Full Resume" button

**Note**: The current resume links (`https://docs.google.com/document/d/1abcd1234567890/edit`) are placeholder URLs. Replace these with your actual Google Docs or other third-party resume hosting service URL.

## Setup and Usage

1. Clone or download the project files
2. Update the resume links in `index.html` to point to your actual hosted resume
3. Open `index.html` in a web browser
4. For development, use a local server for best experience

## Customization

To customize the website with your own information:

1. **Personal Information**: Update name, contact details, and descriptions in `index.html`
2. **Resume Links**: Replace the placeholder Google Docs URLs with your actual resume link
3. **Projects**: Modify the project cards with your own projects and GitHub links
4. **Experience**: Update the timeline with your professional experience
5. **Skills**: Customize the technical skills sections
6. **Styling**: Modify colors, fonts, and layout in `styles.css`
